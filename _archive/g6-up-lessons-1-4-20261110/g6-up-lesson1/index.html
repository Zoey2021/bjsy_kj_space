0 · 情景导入

为什么要用算法？

同样是统计投票，人工统计和计算机统计有什么不同？

0

人工统计

同学们逐张查看选票，记下每一票，再反复核对总数。人数少时可以完成，人数多时容易慢，也容易漏记或重复。

计算机统计

把投票规则写成算法，再用程序重复处理每一票。只要规则清楚，计算机就能快速、连续地完成统计。

人工

一张一张数，人多时又慢又容易出错。

计算机

把步骤写清楚，让程序重复做每一票。

在1000名学生投票时，为什么更适合用计算机程序统计？

#用a、b表示A、B作品的得票数，程序初始票数归零
a = 0
b = 0
# 用变量i控制投票的次数
i = 1
# 有多少个人参与投票就循环多少次
while i < 1001:
    #提示用户投票的方式，并用tp存储用户输入的投票内容
    tp = input("输入a投票给A作品，输入b投票给B作品。")
    #对tp中的内容进行判断，并不断统计A、B作品票数
    if tp == "a":
        a = a + 1
    else:
        b = b + 1
    i = i + 1
# 输出将A、B作品的票数
print("A作品获得票数为：", a, "，", "B作品获得票数为：", b)
想一想：如果输入既不是 a 也不是 b，会走到 else。
