🔁 活动三：百钱买百鸡 — 理解双层枚举（嵌套循环）

公鸡5文、母鸡3文、小鸡3只1文。100文买100只。
枚举 公鸡 0~20，每选定一个公鸡数，再枚举 母鸡 0~33，小鸡自动算出。
🔵 外层循环：枚举公鸡 gong
gong = 0 （范围 0~20）
🟡 内层循环：枚举母鸡 mu
mu = 0 （范围 0~33）
小鸡 = 100 - 0 - 0 = 100 只
总价 = 5×0 + 3×0 + 100/3 = 33.33 文
公鸡母鸡小鸡总价=100?

💡 鸡兔同笼 = 一层循环（枚举鸡 0~35，共36种可能）
百钱买百鸡 = 两层循环（外层公鸡 0~20，内层母鸡 0~33，共 21×34=714 种组合）
这就是"嵌套循环"——循环里面套循环！
