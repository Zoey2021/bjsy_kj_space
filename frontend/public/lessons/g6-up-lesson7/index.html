▲ AI 辅助生成的参考程序（有 6 个词被“猫叼走”了 →）


          

            
input()
让玩家在键盘上输入。注意：得到的是文字，不能直接比较大小。

            
int()
把文字变成整数。int("30") 才能参加数学比较。

            
import random
导入随机模块；randint(1,100) 让计算机从 1~100 里“抽签”。

            
if / else
双分支条件语句：满足条件做一件事，不满足做另一件事。

            
while
循环：条件成立就一直重复，猜不对就“再来一次”。
