# 浙教版（2023）六年级上册《第3课 算法设计》教学设计（公开课）

---

## 一、教学内容梳理

### 1.1 课题位置

| 项目 | 内容 |
|------|------|
| 教材版本 | 浙江教育出版社（2023版） |
| 年级 | 六年级上册 |
| 单元 | 第一单元《算法的实现》 |
| 课题 | 第3课 算法设计 |
| 课时 | 1课时（40分钟） |
| 教学环境 | 计算机教室 + 一体机投影 + 流程图绘制工具 |

**前后衔接**：
- 前接：第2课《抽象与建模》——学生已学会用表格抽象问题并建立计算模型（鸡兔同笼：`ji+tu=35, 2×ji+4×tu=94`；百钱买百鸡：模型已建，留悬念"下节课设计算法求解"）
- 本课：聚焦三步骤中的第二步——**设计算法**。核心新知是**枚举法**：确定枚举范围和正确解的判断条件，用流程图表示算法
- 后启：第4课《验证算法》——将设计的算法用编程实现并验证

### 1.2 教材核心内容

#### 知识点

1. **枚举法思想**——把问题的所有可能解**一个一个列举出来**，逐一检验，找出正确解
2. **枚举法的两个关键**——①枚举范围（从哪到哪）②正确解的判断条件（用什么标准检验）
3. **枚举法的一般流程**——开始 → 取第一个枚举值 → 判断是否在范围内 → 判断是否满足条件 → 输出/取下一个
4. **算法设计的步骤**——确定枚举对象 → 确定范围 → 确定判断条件 → 绘制流程图

#### 教材案例

| 案例 | 用途 |
|------|------|
| 鸡兔同笼（枚举鸡的只数） | 新知讲解核心案例 |
| 枚举表格（逐行列出所有可能） | 发现规律、确定流程 |
| 百钱买百鸡（迁移应用） | 用枚举法解决新问题 |

## 二、教学目标

- **信息意识**：能说出枚举法的基本思想；能列举生活中运用枚举法的例子（密码验证、查找物品等）
- **计算思维**：能针对具体问题确定枚举对象、枚举范围和正确解的判断条件；能用流程图表示枚举法的完整算法；能体会枚举法中循环和分支两种控制结构的组合运用
- **数字化学习与创新**：能借助流程图工具绘制完整的枚举法算法；能将鸡兔同笼中习得的枚举法迁移到百钱买百鸡问题
- **信息社会责任**：通过讨论"密码连续输错3次锁定"等生活场景，理解枚举法的两面性（解决问题的工具 vs 暴力破解的手段），建立信息安全意识

## 三、学情分析与教学策略

### 3.1 六年级学生的真实起点

| | 学生会 | 学生不会 |
|------|--------|----------|
| 鸡兔同笼 | 第2课已建好模型 `ji+tu=35, 2×ji+4×tu=94` | **不会把这个模型转化为求解算法** |
| 流程图 | 第1课学过起止框、处理框、判断框、流程线 | 不熟悉循环结构（重复执行一段→返回判断）的回连画法 |
| 枚举 | 生活中用过（"一个一个试"如试密码），但不知道这叫"枚举法" | 不会把"一个一个试"抽象为算法结构 |
| 百钱买百鸡 | 第2课只建了模型，未求解 | 需要把鸡兔中学到的枚举法迁移过来 |

### 3.2 公开课三大设计原则

1. **承前启后，项目制驱动**——从上课一开始就用"我们上节课建好了鸡兔同笼的模型，今天设计算法把它解出来"串联两节课，让学生感受到项目推进的节奏
2. **从具象到抽象，表格再出场**——先用"手工枚举"让学生亲身体验"一个一个试"的过程并填表，再从表格中归纳出枚举法的规律，最后用流程图表达
3. **流程图是本课的核心产品**——每个学生下课时手里都有一张自己画的鸡兔同笼枚举法流程图。评课者翻开任何一个学生的笔记本，都能看到一个完整的算法设计

## 四、五环节教学过程设计

### 环节一：回顾导入——"上节课建好了模型，今天把它解出来！"（约4分钟）

**环节目的**：快速回顾第2课成果，建立单元项目推进感，引出本课课题。

---

**教师活动**：

**1. 回顾模型（约1分钟）**

> PPT展示第2课最后留下的鸡兔同笼计算模型：
>
> `ji + tu = 35`
> `2×ji + 4×tu = 94`
>
> "上节课我们用表格做抽象建模，得到了这两个方程。还记得这是什么吗？"

学生回应：鸡兔同笼的计算模型。

> "模型有了——但怎么求解？你说一句'计算机，帮我解'，计算机会吗？不会。"
>
> "你得告诉计算机**一步一步怎么做**——这就叫**设计算法**。"

**2. 揭示课题（约1分钟）**

> PPT展示课题：**第3课 算法设计**
>
> "今天要学的算法，名字有点好玩——叫**枚举法**。听起来高深，其实就是你每天都在做的事：**一个一个试**。"

**3. 激活生活经验（约2分钟）**

> "你在生活中用过'一个一个试'吗？举个例子？"

引导学生说出：试密码（000到999）、找东西（每个抽屉打开看）、猜数字（1到100）。

> "没错！枚举法的核心就两件事："
>
> PPT展示：**① 从哪试到哪？（枚举范围） ② 怎么判断试对了？（判断条件）**
>
> "今天我们就用这个最朴素的方法，让计算机自己找出鸡和兔各有几只。"

**学生活动**：
- 回忆上节课的计算模型
- 举手说出生活中"一个一个试"的例子
- 齐读枚举法的两个关键

> **设计意图**：最短路径回顾第2课成果，建立"模型→算法"的逻辑链。用生活例子消除"枚举法"的陌生感——告诉学生这节课不是学新东西，而是给"你每天都在做的事"起个名字并学会用流程图画出来。

---

### 环节二：新知讲解——枚举法的思想与流程（约12分钟）

**环节目的**：通过"手工枚举 → 填表发现规律 → 归纳流程图"三步，让学生从亲身体验中理解枚举法的完整流程。

---

#### Step 1：手工枚举——"我们来一个一个试"（约4分钟）

**教师活动**：

> "鸡和兔共35只。鸡可能是几只？"

学生：0只、1只、2只……最多35只。

> "好，鸡从0到35——这就是**枚举范围**。"
>
> "怎么判断某个数字对不对？"

引导学生说出：如果鸡是ji只，那么兔是`35-ji`只。代入第二个方程 `2×ji + 4×(35-ji)` 看看等不等于94。

> "等于94就是正确答案——这就是**判断条件**。"

**出示枚举表格（PPT逐行展开）**：

| 鸡的只数 ji | 兔的只数 tu = 35-ji | 总脚数 = 2×ji + 4×tu | 是否等于94？ |
|:---------:|:-----------------:|:--------------------:|:--------:|
| 0 | 35 | 140 | ✗ |
| 1 | 34 | 138 | ✗ |
| 2 | 33 | 136 | ✗ |
| … | … | … | … |
| 23 | 12 | **94** | **✓** |
| … | … | … | … |
| 35 | 0 | 70 | ✗ |

> "你看到了——我们只枚举了鸡的只数（0到35），每试一个数就自动算出兔的只数和总脚数，总脚数等于94的那个就是答案。这就是枚举法。"

**学生活动**：
- 跟着教师的节奏，理解枚举对象（鸡的只数）、枚举范围（0~35）、判断条件（总脚数=94）
- 看PPT逐行展示枚举表格，感受"一个一个试直到找到对的"

---

#### Step 2：归纳规律——"每次试有什么相同的步骤？"（约3分钟）

**教师活动**：

> "观察表格——你每一次'试'，做了什么？"

引导学生归纳出每次循环的四件事：
1. 取一个鸡的数量（从0开始）
2. 算出兔的数量（35-ji）
3. 算出总脚数，判断是否=94
4. 如果是 → 输出答案；如果不是 → 取下一个

> "这四件事中，哪些每次都不变、哪些每次变？"

学生发现：计算方式不变（总是35-ji、2×ji+4×tu），变的只有ji的值（每次+1）。

> "不变的写成流程图里的'处理步骤'，变的交给'循环'来自动处理——这就是从表格到流程图的思路。"

**学生活动**：
- 讨论"每次试的步骤"，归纳出重复的模式
- 辨识"不变的"（处理方式）和"变的"（ji的值）

---

#### Step 3：画流程图——"把你的思路画出来"（约5分钟）

**教师活动**：

> "现在我们把刚才的思路，用流程图表示出来——流程图元素还记得吗？第1课学过。"

快速回顾：圆角矩形=开始/结束，矩形=处理，菱形=判断，箭头=流向。

**教师一步步在PPT/板书上画出枚举法流程图**（学生在笔记本上跟着画）：

```
开始 → ji = 0 → ji ≤ 35? → 否 → 结束
                ↓ 是
         tu = 35 - ji
                ↓
    2×ji + 4×tu = 94? → 否 → ji = ji + 1 → 回到判断
                ↓ 是
         输出 ji, tu
                ↓
             结束
```

**每一步都提问后再画**：

| 教师问 | 画什么 |
|--------|--------|
| "从哪开始？" | 画起止框「开始」 |
| "鸡从几开始试？" | 画处理框「ji = 0」 |
| "试到什么时候为止？" | 画判断框「ji ≤ 35?」——否→结束 |
| "每试一个ji，先算什么？" | 画处理框「tu = 35 - ji」 |
| "怎么判断对不对？" | 画判断框「2×ji+4×tu = 94?」 |
| "不对怎么办？" | ji+1，箭头绕回到 ji≤35 的判断 |
| "对了怎么办？" | 画输出框，箭头到结束 |

**完成后的关键追问**：

> "这道流程图中，哪个箭头是往上回的？回了几次？" → 学生指出 ji=ji+1 到判断框的回线，一共回了23次才找到答案
>
> "这个'回'就是循环——计算机最擅长的事。人算23次嫌累，计算机一秒算完。"

**学生活动**：
- 在笔记本上跟着教师一步一步画出完整流程图（本课核心产品）
- 同桌互相检查：流程线方向写对了吗？判断框有两个出口吗？回线画了吗？

> **设计意图**：环节二是全课的核心。"手工枚举填表 → 归纳规律 → 画流程图"三步紧密相扣。手工枚举让学生亲身体验"一个一个试"的过程（这是具象），归纳规律让学生发现每次的重复模式（这是提炼），画流程图让学生用符号化语言表达算法（这是抽象）。三者递进，从"做"到"想"到"画"，完全符合六年级学生的认知规律。流程图的每一步都经过追问才画，确保学生理解"为什么这样画"而非"照着描"。

---

### 环节三：探究活动——你画一张、你迁移一次（约14分钟）

**环节目的**：第一个探究让学生在变式题上独立画完整流程图（巩固），第二个探究让学生将枚举法迁移到百钱买百鸡（创造）。

---

#### 探究一：农场版鸡兔同笼——独立画流程图（约6分钟）

**教师出示题目**：

> "还记得第2课的农场鸡兔同笼吗？20个头、56只脚。你的任务——**画出完整的枚举法流程图。**"

**PPT展示提示卡**（不给完整答案，只给三个关键问题的填空）：

```
□ 枚举对象：_______
□ 枚举范围：_______ 到 _______
□ 判断条件：___________________
```

**学生先完成这三个空**（约1分钟），全班核对后再画流程图（约4分钟）。

**核对三个关键**（约30秒）：对象=鸡的只数、范围=0到20、判断=`2×ji + 4×(20-ji) = 56`

> "三个空填对了，画图就不难——和刚才画的35头94脚的图，结构一模一样，只换了数字。"

**教师巡堂策略**：

| 现象 | 回应 |
|------|------|
| 三个空写不出来 | "回顾第2课的鸡兔表格——对象是谁？范围是从几只到几只？" |
| 流程图结构正确但数字忘改 | "20和56改了吗？用红笔圈出来检查。" |
| 回线忘记画 | "如果试到第5只鸡，算出来不对——下一步是什么？箭头应该指向哪？" |

**同桌交换检查后屏幕投影标准答案**（约30秒）。

---

#### 探究二：百钱买百鸡——迁移枚举法（约8分钟）

**教师激情引入**：

> "第2课的百钱买百鸡，我们建了模型但没求解——模型在这："
>
> `gong + mu + xiao = 100`
> `5×gong + 3×mu + xiao/3 = 100`
>
> "今天我们来设计算法！和鸡兔同笼一样——枚举法。但这次有三个对象（公鸡、母鸡、小鸡），怎么枚举？"

**分步讨论（约5分钟）**：

**第1步：确定枚举对象（约1分钟）**

> "三个动物，枚举哪一个？"

四人小组讨论30秒。全班交流。

引导学生：枚举公鸡（0到100）和母鸡（0到100），小鸡自动算（`xiao = 100 - gong - mu`）。如果只枚举公鸡，母鸡的范围也需要确定。

> 最终方案：**枚举公鸡从0到20**（因为5×gong≤100，所以gong≤20），**枚举母鸡从0到33**（因为3×mu≤100，所以mu≤33），小鸡自动算出。

**第2步：确定判断条件（约1分钟）**

> "什么情况下，一组（gong, mu, xiao）是正确答案？"

学生回答：两个条件同时满足——① `gong + mu + xiao = 100` ② `5×gong + 3×mu + xiao/3 = 100`

> "注意！第二个条件要整除——小鸡的只数 xiao 必须能被3整除。"

**第3步：画流程图（约3分钟）**

> "和鸡兔同笼的区别是什么？"

引导学生发现：鸡兔同笼是**一层循环**（枚举鸡），百钱买百鸡是**两层循环**（枚举公鸡，内层再枚举母鸡）——嵌套循环。

教师出示半成品流程图框架（PPT），学生填空完成关键位置：

```
开始
  ↓
gong = 0 → gong ≤ 20? → 否 → 结束
                ↓ 是
         mu = 0 → mu ≤ 33? → 否 → gong = gong + 1 → 回到外层
                        ↓ 是
                 xiao = 100 - gong - mu
                        ↓
          5×gong + 3×mu + xiao/3 = 100 且 xiao能被3整除?
                   ↓ 是                    ↓ 否
            输出 gong, mu, xiao      mu = mu + 1 → 回到内层
```

**第4步：不要求完整画完——只要理解"两层循环"（约1分钟）**

> "这张图比鸡兔同笼多了什么？" → 多了一层循环（内层mu）和一条回线
>
> "这就是枚举法的威力——不管问题多复杂，思路都一样：**定范围，逐个试，条件判断**。"

**学生活动**：
- 探究一：独立完成农场鸡兔流程图（4-5分钟，在笔记本上画）
- 探究二：小组讨论确定枚举对象和范围 → 看教师演示嵌套循环框架 → 理解"两层循环就是一层套一层"

> **设计意图**：探究一是"结构不变、只换数字"的巩固训练，确保每个学生都能独立画出一张完整的枚举法流程图。探究二是从"一层循环"到"两层循环"的思维跃迁——教师出示半成品框架而非让学生从零画起，既降低了技术门槛，又保留了对"嵌套循环"这一核心概念的理解要求。两个探究形成一个清晰的难度台阶，评课者可以看到全班在探究一的高完成率和探究二的小组讨论热度——这就是差异化教学的设计。

---

### 环节四：反思提升——枚举法的威力与边界（约6分钟）

**环节目的**：把枚举法的思想升华为可迁移的通用方法；通过信息安全讨论建立算法的社会责任意识。

---

#### 活动1：总结枚举法公式（约2分钟）

**教师活动**：

> "今天我们设计的两个算法——鸡兔同笼和百钱买百鸡——有什么共同点？"

引导学生归纳：

```
枚举法的公式：
  ① 确定枚举对象（枚举谁？）
  ② 确定枚举范围（从几到几？）
  ③ 确定判断条件（什么算正确？）
  ④ 用流程图表达（循环 + 分支）
```

> "记住这个公式——以后遇到任何'有多个可能答案'的问题，公式一上，算法就出来了。"

**活动2：生活迁移——密码锁与枚举法（约2分钟）**

> "一个3位数字密码锁，密码可以从000试到999。如果你写程序来试——最多试多少次？"

学生：1000次。

> "计算机一秒试100万次——1000次只要0.001秒。所以——**

PPT出示：

```
⚠️ 枚举法是一把双刃剑
  ✅ 正方：帮我们解决鸡兔同笼、百钱买百鸡
  ❌ 反方：被坏人用来暴力破解密码
```

> "这就是为什么——登录网站时密码连续输错3次，账号就会被锁定。为什么ATM机输错3次密码就吞卡？"

引导学生：**防止坏人用枚举法暴力破解**。

> "所以枚举法告诉我们：**
> ① 作为程序员，你要会用枚举法解决问题
> ② 作为用户，你要设复杂密码，别让人轻松枚举出来"

**活动3：Python演示（约2分钟）**

> 打开Python环境，展示鸡兔同笼枚举法代码：

```python
for ji in range(0, 36):
    tu = 35 - ji
    if 2 * ji + 4 * tu == 94:
        print("鸡:", ji, "只，兔:", tu, "只")
```

> 回车运行 → 0.1秒出结果："鸡: 23 只，兔: 12 只"
>
> "看到了吗？刚才我们画在纸上的流程图，变成代码就是这样——四行。你的流程图就是代码的设计图——**先画图，再写代码**。"

**学生活动**：
- 归纳枚举法公式
- 讨论密码锁问题，建立信息安全意识
- 看Python演示，感受"流程图→代码"的转化

> **设计意图**：信息安全意识的植入是本环节的亮点——不是生硬地说教"枚举法要注意安全"，而是用密码锁这个每个学生都接触过的场景，让学生自己推导出"枚举法也可以被坏人利用→所以要设复杂密码→系统要加限制"。这种"从算法原理到社会责任"的推导过程，比直接告知"要有安全意识"深刻得多。最后的Python演示再次呼应第2课的"表格→代码"闭环，建立"流程图→代码"的闭环。

## 六、公开课特别备忘

| 关注点 | 本课做法 |
|--------|----------|
| **与教材一致性** | 严格遵循教材"枚举法"主题：微课介绍枚举法思想→确定范围和判断条件→枚举表格→流程图→百钱买百鸡迁移 |
| **与第2课衔接** | 开场直接用第2课最后的鸡兔模型 + 百钱百鸡悬念，让学生感受项目推进感 |
| **学生动手频率** | 环节二（跟画流程图）、探究一（独立画流程图），全课学生动笔时间≥12分钟 |
| **信息科技味** | 流程图是核心产品；结尾Python演示建立"流程图→代码"转化；信息安全讨论体现"算法与社会" |
| **可观察的学习证据** | 笔记本上的完整流程图（探究一）；举手的选择题作答；自评表 |
| **差异化支持** | 探究一独立完成（人人过关），探究二小组讨论+半成品框架（降低门槛）；巡堂时对薄弱学生直接给出三个关键空的答案 |
| **时间控制** | 环节二12分钟最紧张——画流程图时每一步不超1分钟，教师画得干净利落；探究二8分钟如超时，嵌套循环只展示不要求每个学生画完 |
| **过渡语** | 每环节结束都有一句向前的勾连句——"好，枚举法你学会了，接下来你自己画一个"→"画得不错，接下来我们挑战更难的百钱买百鸡" |

> **依据课标**：《义务教育信息科技课程标准（2022年版）》第三学段"身边的算法"——"能用自然语言、流程图等方式，基于算法的顺序、分支和循环三种基本控制结构，正确进行问题求解的算法描述"。本课以鸡兔同笼和百钱买百鸡为案例，通过"手工枚举→填表归纳→画流程图"三步骤，帮助六年级学生掌握枚举法算法设计，重点体会循环和分支的组合运用。
